# 🚀 LAB 9 - SPRING BOOT JWT AUTH

## 📌 Descripción
Este proyecto implementa autenticación y autorización con **Spring Boot + JWT**, permitiendo registro de usuarios, login y acceso a rutas protegidas por roles (USER / ADMIN).
